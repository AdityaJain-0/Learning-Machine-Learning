Support Vector Machines (SVM) tries to draw a line between that seperates class (classification model) while leaving maximum margin between them --> Tries to draw a line as far away from all points as possible (less focused on probabilities)

How it works?

    SVM works by finding a hyperplane --> A line in a 2d model, a plane in a 3d model, etc that seperates the data classes and maximizes the distance between the hyperplane and the nearest data points from each class 

    The closest points are called support vectors --> They define the boundary 

        Support vectors are found by finding points that lie on (usually) --> Known as the margin
        
            w * x + b = +/- 1

    SVM finds this widest possible gap by doing something like the following

        Lets say we have a 2d model so that the hyperplane is defined by:

            w * x + b = 0

        The following optimization is solved

            min(0.5 * ||w||^2) subject to y(w * x + b) >= 1

    A perfect seperation is not always possible in which case SVM introduces slack variables to allow for some error --> known as soft-margin SVM 

        min(0.5 * ||w||^2 + c * summation (E))

            E = how much each point violates the margin 
            c = how harshly to punich those violations


            where c is a hyperparameter

                large c = fewer misclassifications (low bias, high variance)

                    The model is strict on misclassifications. It will try to classify everything correctly, even if the margin has to be small. More likely to overfit on noisy data.

                small c = allows more flexibility (higher bias, lower variance)

                    The model is lenient on misclassifications. It focuses on finding a wider margin, even if that means some points are on the wrong side. Great for noisy data, avoids overfitting.
