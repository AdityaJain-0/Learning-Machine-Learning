Unlike linear regression, logistic regression is all about binary classification 
    * Spam or not
    * Tumor malignant or benign 

    Your input features and ouput work on a probablity (between 0 and 1) and then you classify based on a threshold (usually 0.5)

    Math

        We start with a linear Equation

        z = w1x1 + w2x2 + w3x3 + ... + wnxn + b

        But instead of outputting z, we pass is through a sigmoid function -> cruches any real number to between 0 and 1

        y(hat) = sigmoid activation = 1 / (1 + e^(-z))

            y(hat) > 0.5 evaluate 1
            y(hat) < 0.5 evaluate 0

        The corection process we use is not MSE but instead Binary Cross Entropy (BCE) used for classification problems

        loss/accuarcy = BCE = -(y * log (y(hat)) + (1 - y) * log(1 - y(hat)))

            * Penalizes confident but wrong answers a lot 
            * y = correct classification

        Optimization = gradient

            Once again we take the partial derivative of the loss function in regard to all our weights and then update and repeate 

            Lets say z = w1x1 + b --> during the optimization step we would take the partial derivative of the loss fucntion in regards to w1 and then in regards to b 

    What is standerdization?

        Standerdization is used to combat feature scale. For example, features such as age or income may have a much greater range then something like height. For models that use multiple features, features that have greater scale hold more weight in the gradient without standerdization, this leads to these features being more dominate --> Model may struggle to converge or converge very slowly --> Gradient becomes unstable/inefficent

        X(scaled) = (x - u) / of

        u = mean
        o = standered deviation 

        When you standerdize, you make it so that the feature x has a mean of 0 and a deviation of 1
