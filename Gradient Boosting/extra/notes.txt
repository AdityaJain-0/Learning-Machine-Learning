Boosting is a ensamble method that sequentialy combines multiple weaker models (usually decision trees) to build a stronger model, each tree corrects the mistake of the previous one 

    Imagine you're guessing house prices:

        1. (weak model): You guess a flat $300k for all houses, not great
        2. (next model): You now try to fix the worst mistakes --> maybe small houses were overestimated, big ones underestimated
        3. You look at what’s still wrong and try to fix that again
        4. You keep adding small tweaks until you're pretty close to reality

How it works

    1. Start with the inital prediction 
        Regression = mean value
        Classification = log-odd 
    2. Compute residuals (errors)
        How far is each point from the prediction
            Regression = MSE 
            Classification = logloss 
    3. Fit a "weak" learner to the residuals -> Shallow tree
        Tree learns to correct current model errors 
    4. Add the new tree's prediction to the overall model 
        Each new tree is added with a learning rate 𝛼 to control its influence
    5. Repeat
        With each new tree, the model gets stronger --> Min(error)

The gradient in gradient boosting refers to lowering the loss per cycle of training with a gradient. The residuals are the gradients of the loss with respect to the predictions. Each tree descends the gradient by trying to predict the negative gradient (residuals). 

XGBoost --> eXtream Gradient Boosting

    * XGBoost is an optimized and regularized implementation of gradient boosting:
    * Built for speed and performance
    * Prevents overfitting with L1/L2 regularization
    * Uses parallel processing
    * Has pruning to eliminate useless splits
    * Handles missing values smartly
